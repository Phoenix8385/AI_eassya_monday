# AI Essay Detector — Callus Hiring Challenge (Project 2D)

A detector for AI-generated admissions essays that measures signals, not opinions — a trained classifier makes the call, not a chat model.

---

## 🧠 What It Does

- Pastes essay in → returns a probability + plain-language explanation, not a bare percentage
- Flags specific sentences with evidence, not just an overall score
- Never sends the essay to a chat model and relays its opinion — this is explicitly NOT a wrapper

---

## 🔬 How Detection Actually Works

- Runs the essay through a local **GPT-2 model** to measure token-level predictability (perplexity)
- Measures **burstiness** — sentence-to-sentence rhythm variance (AI text is smoother, humans are uneven)
- Measures **vocabulary diversity**, **phrase repetition**, and **transition-word overuse**
- All 5 signals feed into **one trained classifier** (Logistic Regression) — our own code decides, not the language model
- Uses `predict_proba()`, not a bare label — output is always framed as a probability with a caveat, never "100% AI detected"

## 🧰 Tech Stack

- **Backend:** Python, FastAPI, HuggingFace Transformers (GPT-2), scikit-learn
- **Frontend:** React (TypeScript), Framer Motion, React Three Fiber (3D hero)
- **Deployment:** Render (backend) · Vercel (frontend)

---

## 💻 Running Locally

**Backend:**
- `cd backend`
- `python -m venv venv` → activate it
- `pip install -r requirements.txt`
- `uvicorn app.main:app --reload --port 8000`
- Test: `http://localhost:8000/health`

**Frontend:**
- `cd frontend`
- `npm install`
- `npm run dev`
- Open `http://localhost:5173`

---

## 📊 Dataset

- Base dataset: Kaggle "LLM - Detect AI Generated Text" (DAIGT) — thousands of labeled human/AI student essays
- Hard-case subset: 40 human essays lightly polished by an LLM, labeled separately as `ai_polished`
- Full sourcing, scope, and gaps documented in `backend/DATASET.md`

---

## 📈 Evaluation

- Full accuracy/precision/recall/F1 reported in `backend/EVALUATION.md`
- Accuracy reported **separately** for raw AI essays vs. AI-polished essays — the harder case is not hidden inside one blended number
- Includes 3 confidently-wrong predictions with explanation, and an honest discussion of the ESL-writer bias risk

## ⚠️ Known Limitations

- Currently hitting Render's free-tier 512MB memory limit with full GPT-2 loaded — being resolved by switching to `distilgpt2` for a smaller memory footprint
- Dataset is mostly argumentative/persuasive student essays — likely underrepresents STEM and creative-writing styles
- ESL-writer bias not directly testable — dataset has no first-language labels; discussed as an open risk in `EVALUATION.md`
- No support yet for essays generated by AI models newer/different from what's represented in the training data
